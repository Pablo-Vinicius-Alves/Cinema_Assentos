# Organizar Assentos Na Sala de Cinema 

## Sobre: 

Este repositório tem como objetivo simular uma reserva em uma sala de cinema. 

Objetivo do projeto(Em andamento)

* Criar uma sala com N fileiras e X assentos por fileira.
* Cada assento tem um identificador.
* Visualizar todos os assentos disponíveis.
* Reservar assento se estiver livre.
* Cancelar reserva em um assento já reservado.
* Reservar os assentos no melhor lugar.
* Aplicar um desconto caso compre muitos ingressos.
